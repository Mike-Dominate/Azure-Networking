# Lab 21 — Network Troubleshooting Incident Lab

## Status
`NOT STARTED`

## Purpose
Diagnose a deliberately broken Azure network without being told which component is at fault.

## Must cover
- DNS resolution
- NSG/effective security
- routes/next hop
- NAT/SNAT
- load balancer health
- firewall policy
- private endpoint/DNS interactions
- Network Watcher tools
- flow logs and Azure Monitor evidence
- symptom -> hypothesis -> test -> root cause -> fix -> verification workflow

## Independence rule
This lab should be substantially learner-driven. Do not reveal the fault before investigation.
