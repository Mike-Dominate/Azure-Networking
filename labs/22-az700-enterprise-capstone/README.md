# Lab 22 — AZ-700 Enterprise Capstone

## Status
`NOT STARTED`

## Purpose
Design, defend and implement an end-to-end Azure network architecture spanning the current AZ-700 domains.

## Scenario requirements
- multi-region Azure environment
- hub/spoke or Virtual WAN decision
- hybrid branch/datacentre connectivity
- remote-user access
- private PaaS access
- global and regional application delivery
- centralized inspection/security
- DNS and routing design
- monitoring/diagnostics
- high availability and disaster recovery
- cost and operational trade-offs

## Deliverables
- architecture diagram
- IP/addressing plan
- service-selection decision record
- traffic/control-plane flows
- security controls
- routing/DNS plan
- validation strategy
- failure/troubleshooting scenarios
- Terraform for practical components
- final design defence and explain-back

## Independence rule
The learner should select and justify services from requirements rather than follow a prescribed build recipe.
