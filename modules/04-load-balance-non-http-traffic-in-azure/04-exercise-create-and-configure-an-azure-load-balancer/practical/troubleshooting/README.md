# Lab 01 — Troubleshooting Journal

Use this file to capture real troubleshooting, not hypothetical answers.

## Troubleshooting format

For every issue record:

### Symptom

What failed or looked wrong?

### Initial hypothesis

What did we think might be causing it?

### Evidence gathered

Portal observations, CLI output, HTTP behaviour, probe state, NSG state, VM/service state, etc.

### Root cause

What actually caused the problem?

### Fix

What change resolved it?

### Verification

How did we prove the fix worked?

### Lesson

What should be remembered next time?
