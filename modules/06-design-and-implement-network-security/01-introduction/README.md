# Unit 01 — Introduction

**Microsoft Learn Module 6:** Design and implement network security  
**BlueHarbor chapter:** Connectivity is not security  
**Status:** NOT STARTED

## Business event

BlueHarbor's networking and application-delivery architecture works, but Security now asks whether every successful path is actually appropriate.

## Core mental model

```text
Networking:
Can A reach B?

Security:
Should A reach B?
If yes, by which protocol, port, path and policy?
```

## Objective

Identify the attack surface and security boundaries created by BlueHarbor's public applications, hybrid connectivity, multiple VNets, remote access and outbound Internet requirements before selecting controls.
