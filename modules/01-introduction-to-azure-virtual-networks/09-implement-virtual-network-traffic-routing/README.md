# Unit 09 — Implement virtual network traffic routing

## BlueHarbor chapter: Connectivity exists, but the path must be controlled

Security asks you to control how specific traffic leaves a subnet instead of relying blindly on default routing behaviour.

This unit introduces system routes, user-defined routes, next hops and effective-route troubleshooting.

The practical should deliberately create one routing failure and diagnose it from the effective route.
