# Source Reference

Primary learning reference:

`https://github.com/rithinskaria/kodekloud-az700`

## How we use it

The source repository provides the AZ-700 lab sequence and original learning objectives. We use it to understand what each lab intends to demonstrate.

We do **not** treat its PowerShell scripts, passwords, regions, naming, or portal steps as mandatory implementation choices.

Our implementation may change:

- deployment mechanism
- Azure region
- VM SKU
- authentication method
- resource naming
- security defaults
- validation commands
- Terraform structure
- troubleshooting exercises

provided the original networking concept remains intact.

## Why

The aim is to learn Azure networking as an engineer, not simply reproduce somebody else's script. Each exercise should be explainable, observable, reproducible, and useful later as a reference.
